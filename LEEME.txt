INTEGRANTES: KEVIN GONZALEZ, ISAIAS LOPEZ, VERONICA DOMINICO

TEMA ELEGIDO 

Sistema de gestión de una yerbatería: catálogo público de productos y panel
de administración con ABM (alta, baja, modificación y listado) de categorías
y productos.

BASE DE DATOS

Nombre de la base: yerbatera
Archivo SQL: yerbatera.sql (exportado desde phpMyAdmin, con estructura y
datos de ejemplo).

Tablas:
- categorias (id AUTO_INCREMENT, nombre, descripcion)
- productos  (id AUTO_INCREMENT, categoria_id, nombre, descripcion, precio,
               peso, unidad)  -> unidad: 'g' (gramos) o 'kg' (kilos)
               -> relacionada con categorias por la clave foránea categoria_id
- usuarios   (id AUTO_INCREMENT, usuario, password)

INSTALACIÓN

1. Copiar la carpeta del proyecto dentro de C:\xampp\htdocs\
   (por ejemplo: C:\xampp\htdocs\tp3).
2. Iniciar Apache y MySQL desde el panel de XAMPP.
3. Abrir http://localhost/phpmyadmin e importar el archivo yerbatera.sql
   (pestaña "Importar"). El archivo ya crea y selecciona la base "yerbatera".
   Nota: si ya importaste una versión anterior del archivo (sin los campos de
   peso), agregarlos ejecutando en phpMyAdmin esta sentencia:
   ALTER TABLE productos
     ADD COLUMN peso DECIMAL(10,2) NULL AFTER precio,
     ADD COLUMN unidad ENUM('g','kg') NULL AFTER peso;
4. Revisar el archivo config.php: viene incluido en el .zip con los valores
   por defecto de XAMPP (usuario root sin contraseña). Si tu MySQL usa otros
   datos, cambiarlos ahí.
   En el repositorio de GitHub solo está la plantilla config.ejemplo.php,
   porque config.php queda fuera del repositorio (lo excluye el .gitignore).
5. Entrar a http://localhost/tp3/ (o la carpeta que hayas elegido).

CÓMO PROBARLO (pasos para probarlo)
------------------------------------
1. Inicio: http://localhost/tp3/
2. "Productos": catálogo público de productos (solo lectura).
3. "Administración": ingresar con admin / admin123.
4. Panel -> "Gestionar categorías": crear, editar y eliminar (con confirmación).
5. Panel -> "Gestionar productos": crear un producto eligiendo la categoría en
   el select, editarlo y eliminarlo (con confirmación).
6. "Cerrar sesión" para volver al inicio.

DISEÑO RESPONSIVE (Clase 25)
-----------------------------
La hoja de estilos css/estilos.css se adapta a tres tamaños:
  - Escritorio: tablas tradicionales y formularios en una columna cómoda.
  - Hasta 700 px: el encabezado y el menú se acomodan en vertical y las
    tablas se transforman en tarjetas, mostrando el nombre de cada columna
    al lado del dato (no hace falta desplazarse en horizontal).
  - Hasta 480 px: los formularios, botones y acciones ocupan todo el ancho
    disponible para que se puedan tocar cómodamente en el celular.
También se agregaron estilos de foco visible, mensajes de error/éxito,
botones de peligro para eliminar y un enlace para saltar al contenido.

MODO PRODUCCIÓN (Clase 21)
---------------------------
config.php y config.ejemplo.php definen la constante APP_ENTORNO:
  - 'desarrollo' (por defecto): muestra los errores en pantalla y habilita
    admin.php.
  - 'produccion': no muestra los errores al usuario (los guarda en el log de
    PHP) y deja admin.php deshabilitado.
En un servidor real hay que cambiar APP_ENTORNO a 'produccion' y no subir
config.php al repositorio.
